# Cross Player 1.2.20

This release adds speed presets for quick switching between frequently used playback speeds.

Highlights:
- New Speed Presets setting: write multiple speeds separated by commas (e.g. 1, 1.5, 2, 2.5).
- The media queue speed row now has a presets dropdown that jumps straight to a saved speed.
- Invalid entries are ignored and the dropdown can be hidden by leaving the setting empty.
